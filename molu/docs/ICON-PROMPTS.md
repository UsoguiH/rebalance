# Category icons: ChatGPT image prompts (Uber Eats style)

Generate each icon **1024×1024 PNG with a transparent background**. Then:
1. Save it as `img/icons/<file>.webp`, or send it over and it will be converted.
2. Add the file name (without `.webp`) to `ICON_FILES` in `js/shell.js`.

Until an icon exists, the app shows its emoji.

**For a consistent set:** generate the first icon, then start every following prompt with
*"Same exact style, lighting and colour palette as the previous icon:"*.

## Style block (paste before every subject)
```
Create a single app category icon in the style of Uber Eats category icons: a playful, chunky, slightly 3D flat-vector object with soft cel shading, bold saturated colours, smooth rounded shapes, one gentle top-left highlight, no outlines, no text, no letters, no people's faces. 3/4 front view, centred, filling about 80% of the canvas, isolated on a fully transparent background, no ground shadow, no frame. 1024×1024 PNG.
Subject:
```
