# قدّور: الوضعيات

كل وضعية من ورقة الشخصية تنقص لطبقات (`tools/cut_pose.py` + ملف في `specs/`) وتتحرك على لوب 4 ثواني يتكرر بدون قفزة (`poses.html?p=p1`).

- **p1 الوقفة:** يتنفس، يرمش، يلتفت جنب، يرجع يطالعك ويرفع حواجبه، ويطق العصا في الأرض.
- **p2 التلويح:** يلوّح على إيقاع ثابت، راسه يميل مع التلويحة، يقول «هلا!» مرتين، يرمش.
- **p3 النطة:** ينط في الهوا 4 نطات، يديه بالعصا والكتاب يتحركن بإيقاع مختلف، رجوله ترفس، يضحك، والظل يصغر ويكبر مع الارتفاع.

مبني بطريقة [rossark-motion-skill](../.claude/skills/rossark-motion-skill/SKILL.md) (النسخة المثبتة `9b20964`).

- **تشغيل:** `python3 -m http.server` داخل المجلد وافتح `poses.html?p=p2`.
- **فيديو:** `node tools/video.js "http://localhost:8000/poses.html?p=p2" out.mp4 60 8`.
- **قص وضعية جديدة:** `python3 -I tools/cut_pose.py SHEET.png specs/pN.json pN`.
