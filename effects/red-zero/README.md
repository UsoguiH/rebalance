# Draw a Zero (red)

A red version of the "Draw a Zero" web effect, in two forms.

- `index.html`: an interactive version you can play, drawn on a canvas with no
  build step. Trace a circle with the pointing hand to burn a portal open. Then
  you get the gold star, "You Believed", "College would land You", and the
  meadow. Press and hold (or hold Space) to bring the two hands together.
- `draw-a-zero-red.mp4`: the original screen recording, frame for frame, with
  every green/teal pixel moved to red. The gold star, skin tones and sky are
  left unchanged.
- `recolor.py`: the script that made the video (needs numpy and ffmpeg):
  `python3 recolor.py input.mp4 output.mp4`.
